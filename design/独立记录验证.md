# v0.3.2 独立新条目与当日轮盘

日期：2026-09-08

## 行为

每次有效保存都生成新的 UUID 和保存时间，归入当地日期；同样的正文和心境重新输入后仍可单独记录。保存成功后清空该维度正文、重置心境选择并回到轮盘，标记“已保存 · 新一条”。空白状态无法重复提交。

轮盘只读取本地当天各维度最后一条真实记录，昨日与明日记录均不点亮；以日历日界线区分日期，适配23/25小时夏令时日期。记录页每秒用当前日期刷新，因此跨午夜与回到前台时不会继承昨日火焰。历史保留在总览、对比与导出中。

## 数据保护

新增记录和下一条空草稿一起原子写盘，写盘失败保留原内容并提示重试。编辑器按条目更新标识，旧输入法/心境回调无法把已保存内容写回下一条。

旧版本把已保存内容保留在编辑器，本次用 recordingModeVersion=1 做一次性迁移：只清空与对应维度最新已存正文和心境完全相同、且已选择心境的旧回填副本；其余未保存草稿不变。新版本再次手工输入相同内容的草稿不再被此迁移处理。

iPhone Air 的升级前后本地库已备份并逐字段比较，验证通过：所有历史记录完整不变，仅已保存的回填副本清出，其余草稿不变。真实内容及核对原始文件仅保存在被 Git 忽略的 build/device-backups，未用于截图或提交。

## 测试

完整回归 **36/36 通过**：30 项单元测试与6项界面测试，0失败。使用 iPhone 16e 模拟器（iOS 26.3.1），原始结果摘要见 [test-results-independent-summary.json](test-results-independent-summary.json)。

新增11项数据测试覆盖：独立保存/清空/重启、相同正文再次保存生成不同UUID与时间、空白连点、无历史回填、当日最后记录、当地午夜、夏令时边界、旧版缺省及version0迁移、version1同文未提交草稿保留、写盘失败和恢复重试。

核心 UI 测试实际连续记录 A、B、A，每次保存后正文为空、心境待选、保存禁用；切换标签后仍从新条目开始，对比出现三个独立时间和ID，未保存的下一条不进入历史。原有七维草稿、火焰、时间展示、分享及导入入口也纳入回归。

首轮已通过30项单元测试及4项界面测试，随后 XCTest 在七维草稿输入时持续等待动画结束，故中断该轮。重启模拟器后，对相同代码完整复测36项全部通过，未再出现该等待问题。

Release 真机签名构建成功，v0.3.2 已在 iPhone Air 安装并启动。

## 范围

不删除历史，不清除真正的未保存草稿。导入仍按记录ID去重，不按相同正文去重。本轮未新增AI分析或自动后台任务；语音转写本轮未重新实测。
