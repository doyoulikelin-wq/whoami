# WhoAmI iOS Demo · v0.3.2

## 三个入口

| 入口 | 页面职责 |
| --- | --- |
| 总览 | 纵览七维状态、当天覆盖率和七日活动；不叠加记录按钮。 |
| 记录 | 以轮盘选择一个维度，输入正文与心境，保存快照。 |
| 对比 | 按日期查看维度、具体时间、火焰与数值，进入只读详情。 |

底栏使用原生 TabView。记录本身是一个页面，点击底部“记录”直接进入。采用冷白背景 `#F2F4F6`、正文 `#181E24`、主动作 `#202932` 和钢灰 `#536574`。维持10pt左右的容器圆角，减少独立按钮与卡片堆叠。

## 记录页的三个板块

1. **轮盘。** 完整圆等分七块，约占屏幕三分之一，只放图标；当前维度转至顶部并显示灰色选中区。图标分别采用塔楼、资源叠层、身体、波纹、折页、双环、方向符号的统一线稿。可点选、横滑和沿弧拖动；图标下方的内容区显示完整维度名与引导问题。当天已有记录的维度外缘燃烧黑焰，跨本地午夜或再次进入前台时按当前日期更新，图标始终保持清楚。
2. **内容与心境。** 每个维度保留独立的未保存草稿；正文支持文字和语音转写。心境条三段由浅灰逐渐加深，有明确边界，展示不同形态与大小的火苗。按住拖动映射到1–99，松手收起，只留下火苗；轻点火苗可重新展开。记录页不显示或朗读数值。
3. **保存。** 保存正文与心境为带具体时间的新条目，清空当前输入与心境并回到轮盘；再次进入为新条目。正文与心境选定后可保存，相同内容重新输入也可独立记录。未输入时按钮禁用，避免空白连点。

## 心境映射

| 范围 | 心境 | 火焰 |
| --- | --- | --- |
| 1–33 | 淡漠 | 克制、单支、小幅摆动 |
| 34–66 | 平静 | 有力、稳定、多层轮廓 |
| 67–99 | 冲动 | 多叉、较大、摆动更明显 |

首次需要明确拖选心境，不自动把默认值当作自评保存。数值只在存档/对比页出现；旧版无此字段的记录显示“—”，不补造数值。火焰用原生矢量绘制和轻量动画，尊重系统“减弱动态效果”。

正文区常态保持紧凑，开始输入后展开；键盘上方提供“完成”收起操作。三段背景为 `#DCE1E5`、`#AEB7BF`、`#69747E`，段间有分隔线，深色段采用白字。

## 历史与草稿

七个维度分别保留未提交草稿，切换 Tab 或重启不会丢失。每次保存都创建新 UUID 与保存时间，成功后只清空当前维度的草稿；写盘失败保留输入。历史仅在总览/对比展示，不回填编辑框，也不因跨日删除。

升级以 recordingModeVersion 标记一次性迁移：只有已选择心境、且与该维度最新已保存内容及心境完全相同的旧版回填副本才清空。不同的未提交草稿保留；新版本中再次输入与历史相同的草稿也能跨重启保留。

旧版数据结构保留，新增心境字段使用可选值；新增草稿字典可从旧文件缺省读取。旧版未完成草稿在相应维度恢复，未分类的旧草稿默认在事业维度恢复，保存时以当前选择为准。

## 语音与权限

麦克风按钮按需申请系统权限，不在启动或记录文字前要求授权。支持设备端识别时使用设备端，不支持时由系统 Speech 服务处理。拒绝权限或识别不可用不会阻止文字输入。保存会结束语音并收集末尾转写；切换页面或进入后台释放音频会话。

## 视觉资料

v0.2 的灰黑雕塑图像与图标资产保留；本版总览移除大幅装饰图，把空间用于真实状态。旧版暖色概念图仅作历史资料。本轮以既有冷峻设计系统和本页明确交互规格为依据，用模拟器截图检查实际轮盘、键盘、火焰和只读页面。

## 记录时间与文件

保存时写入完整时间戳。记录页顶部显示当前时分秒；总览最新状态旁显示日期与时分，对比列表和详情显示到秒。导出使用带时区的 ISO 8601 毫秒格式。

总览底部“导入与导出”进入单一文件页面，包含今天/指定日期/全部三个范围及 Markdown/JSON 格式。导出直接打开系统分享，导入使用系统 JSON 文件选择器；不增加底栏入口。JSON 按记录 ID 合并，重复记录保留本地版本，草稿不被覆盖。

示例清理只移除 isDemo 标记的示例对象，不按日期、内容或维度推测哪些记录是示例。新安装从空记录开始。
