# WhoAmI iOS UI · v0.2

这版围绕记录与检视展开：保留事件、状态与判断，再根据原文检查变化。

## 视觉方向

冷白底、石墨黑主要动作、钢灰辅助信息。减少装饰和圆润感：标题采用默认系统无衬线字体，卡片与主按钮使用 10–12pt 圆角，标签使用 7pt 圆角，细分隔线明确结构。维度保留图标与名称，颜色统一为低饱和灰色系。

| Token | 色值 | 用途 |
| --- | --- | --- |
| background | `#F2F4F6` | 页面背景 |
| paper | `#FFFFFF` | 内容表面 |
| ink | `#181E24` | 标题与正文 |
| secondary | `#626D78` | 辅助说明 |
| accent | `#202932` | 主按钮与选中状态 |
| steel | `#536574` | 图标与次级操作 |
| surface | `#E8ECF0` | 次级容器 |
| line | `#D8DEE4` | 边界与分隔 |

角色改为几何人形雕塑与镜中自我，采用冷灰石材、银灰与石墨黑。图像放在首页和档案，不附加无实际结果的点击反馈。首页原始素材见 [companion.png](assets/companion.png)，当前实现见 [四屏总览](screenshots/overview.png)。`reference/today-concept.png` 保留为 v0.1 暖色方案的历史参考，不代表当前视觉目标。

## 语气

用观察、记录、依据、判断和行动表达功能。直接指出信息缺口，区分事实与解释。文案不预设用户正在进步，也不对人格作评价。

| 原表达 | 当前表达 |
| --- | --- |
| 今天，慢慢来。 | 观察自己 |
| 把今天的自己，好好记下来。 | 记录事实。检视判断。 |
| 记一下 | 新增记录 |
| 换个角度，看自己。 | 检视变化 |
| 慢慢认识自己。 | 自我档案 |
| 下一小步 | 下一步行动 |


## 四个固定入口

| 入口 | 主要内容 | 常用操作 |
| --- | --- | --- |
| 今天 | 观察者雕塑、当前状态、最近记录、下一步行动 | 一键记录、更新状态、打开原文 |
| 日记 | 按日分组的记录与当日日记 | 搜索、筛选维度/日期、阅读、编辑、删除 |
| 复盘 | 回顾周期、本地回顾、示例和历史 | 2/3/4 天切换、回看原文、编辑行动与反馈 |
| 我的 | 当前重视的事、七个维度、项目与问题 | 修改档案、管理项目和问题、导出、清除示例 |

所有根页面右上方都可以“新增记录”。首页提供额外的大按钮，输入默认聚焦正文，分类、心情和项目均可选。收起时保留草稿，保存后返回原页面。

## 交互约定

- 使用原生 TabView、NavigationStack、Sheet、表单、日期选择和分享面板，保留熟悉的返回与键盘行为。
- 主要动作触控区至少 44pt；可参考 [Apple 按钮设计规范](https://developer.apple.com/design/human-interface-guidelines/buttons)。
- 四个 Tab 稳定显示，遵循 [Apple Tab 栏设计规范](https://developer.apple.com/design/human-interface-guidelines/tab-bars)，不把记录动作伪装为第五个页面。
- 首次启动直接进入首页。不设登录、邀请码、付费墙、强制建档或 AI 配置前置步骤。
- 删除内容采用系统确认，防止误触；这不会阻止日常使用。无远端审批、审核队列或仓库工作流门禁。
- 复盘主要动作置于长内容之前。信息不足时说明缺口，不生成武断评价。

## 示例、真实记录与 AI

首次运行附带明确标记的示例内容，便于体验完整 UI。自己新增的内容独立保存，设置可清除全部示例；编辑示例仍保留示例标记。清除示例项目会解除相应关联，保留自己写的记录与草稿。

这版“按时间整理”与周期回顾使用本地日期、分类及原文汇集，未调用 AI。虚构复盘持续标为“复盘示例”，不会参与真实回顾。后续接入模型时应保留原文依据与用户修正入口。

## 当前实现范围

SwiftUI 原生 UI，iPhone 竖屏，iOS 17 及以上。数据写入应用沙盒，使用 iOS 文件保护，无账号、服务端请求、分析 SDK 或第三方依赖。支持 JSON 导出，尚无导入、云同步、定时通知、语音录音或真实 AI 服务。

当前以浅色主题为主。更大的辅助功能字号、深色主题、iPad 和横屏将在后续迭代中继续适配。
